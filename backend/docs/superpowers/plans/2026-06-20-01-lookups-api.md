# Lookups API — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) ou superpowers:executing-plans para implementar este plano task-by-task. Os steps usam checkbox (`- [x]`) para tracking.

**Ordem de execução:** Plano **1 de 5**. Independente — pode ser feito em paralelo com o Plano 2. Os planos de frontend (3, 4, 5) consomem estes endpoints.

**Goal:** Expor 4 endpoints de consulta (lookup) servindo **tabelas de referência estáticas** empacotadas no backend, com busca por texto/código: município (IBGE), país (ISO 3166), lista de serviço (LC 116) e NBS. Hoje o frontend usa dados mockados (`src/api/lookups.ts`); estes endpoints substituem esses mocks.

**Architecture:** Módulo de leitura pura `app/modules/lookups/`, sem banco e sem Unit of Work. Os dados ficam em arquivos JSON versionados (`app/modules/lookups/data/*.json`), carregados uma vez em memória no import do módulo. Um `LookupService` faz a busca case-insensitive por `label`/`value`. Router protegido por `get_current_actor` (o front estará autenticado). Os 4 lookups compartilham o mesmo formato de resposta `{value, label}`.

**Tech Stack:** FastAPI, Pydantic, `importlib.resources` para ler os JSON empacotados, pytest.

**Premissas:**
- Os arquivos oficiais de município/país/serviço/NBS serão obtidos das fontes oficiais (IBGE, ISO, LC 116, NBS). Este plano cria o **loader, o serviço, os endpoints e os testes**, e versiona um **subconjunto inicial** (os mesmos valores hoje mockados no front) para destravar o desenvolvimento. A carga completa pode ser substituída depois sem mexer no código.
- `SERVICE_CODE`/`NBS_CODE` de `settings` deixam de ser fonte de emissão (ver Plano 2); aqui viram apenas valores de uma tabela consultável.

- [x] **Step 2: `service.py`** — carrega cada JSON uma vez e faz busca case-insensitive.

```python
# app/modules/lookups/service.py
import json
from functools import lru_cache
from importlib.resources import files

from app.modules.lookups.schemas import LookupOption

_DATASETS = ("municipios", "paises", "servicos", "nbs")


@lru_cache(maxsize=None)
def _load(dataset: str) -> tuple[LookupOption, ...]:
    raw = files("app.modules.lookups.data").joinpath(f"{dataset}.json").read_text("utf-8")
    return tuple(LookupOption(**item) for item in json.loads(raw))


def search(dataset: str, query: str, limit: int = 50) -> list[LookupOption]:
    """Busca por substring em `label` ou prefixo em `value` (case-insensitive).

    Sem `query`, retorna os primeiros `limit` itens.
    """
    options = _load(dataset)
    q = query.strip().lower()
    if not q:
        return list(options[:limit])
    result = [
        opt for opt in options
        if q in opt.label.lower() or opt.value.lower().startswith(q)
    ]
    return result[:limit]
```

- [x] **Step 1: `router.py`** — um endpoint por dataset, todos protegidos por auth.

```python
# app/modules/lookups/router.py
from fastapi import APIRouter, Depends, Query

from app.modules.lookups.schemas import LookupOption
from app.modules.lookups.service import search
from app.modules.users.adapters.http.dependencies import get_current_actor

router = APIRouter(dependencies=[Depends(get_current_actor)])


def _endpoint(dataset: str):
    async def handler(
        q: str = Query("", description="Texto de busca"),
        limit: int = Query(50, ge=1, le=200),
    ) -> list[LookupOption]:
        return search(dataset, q, limit)
    return handler


router.add_api_route(
    "/municipios", _endpoint("municipios"), response_model=list[LookupOption]
)
router.add_api_route("/paises", _endpoint("paises"), response_model=list[LookupOption])
router.add_api_route(
    "/servicos", _endpoint("servicos"), response_model=list[LookupOption]
)
router.add_api_route("/nbs", _endpoint("nbs"), response_model=list[LookupOption])
```

```python
from app.modules.lookups.service import search


def test_busca_por_label():
    res = search("municipios", "jaraguá")
    assert any(o.value == "4208906" for o in res)


def test_busca_por_prefixo_value():
    res = search("paises", "BR")
    assert res and res[0].value == "BRA"


def test_query_vazia_respeita_limit():
    assert len(search("servicos", "", limit=2)) <= 2


def test_case_insensitive():
    assert search("municipios", "JARAGUA") == search("municipios", "jaragua") or \
        any("Jaraguá" in o.label for o in search("municipios", "jaragua"))
```
